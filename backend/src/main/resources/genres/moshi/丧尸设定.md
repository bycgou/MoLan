# 丧尸设定指南

> **核心原则**: 丧尸是末世小说的"自然灾害"。好的丧尸设定 = 清晰的变异机制 + 合理的弱点设计 + 可控的威胁升级。

---

## 1. 丧尸起源与变异机制

### 技巧 A: 起源设定的三种范式
丧尸的起源决定了整部小说的世界观基调。

**起源范式对比表**:

| 范式 | 起源 | 代表作品 | 核心特点 | 适合题材 |
|------|------|---------|---------|---------|
| **病毒范式** | 生化病毒泄露/变异 | 《生化危机》《行尸走肉》 | 科学感强，可感染 | 硬核末世、军事向 |
| **灵气范式** | 灵气复苏/天地异变 | 《我有一座末日城》 | 玄幻感，可进化 | 异能流、进化流 |
| **寄生范式** | 外星寄生/变异生物 | 《寄生兽》《异形》 | 恐怖感，有智慧 | 科幻向、恐怖向 |

**写作建议**:
```
✅ 选一种范式，全书统一，不要混搭
✅ 起源可以在后期揭示，制造悬念
✅ 起因要能解释"为什么是现在爆发"——需要一个触发条件
```

---

### 技巧 B: 感染机制设计
感染机制是丧尸设定的核心逻辑，必须自洽。

**感染路径设计**:
```markdown
## 丧尸感染机制模板

### 感染途径（必须明确）
1. **咬伤/抓伤**: 最常见，通过体液传播
2. **空气传播**: 增加紧迫感，但要限制范围（密闭空间）
3. **水源污染**: 长期威胁，解释大规模感染
4. **母婴传播**: 制造伦理冲突

### 感染时间线（必须量化）
- 潜伏期：被咬后多久会发作？（2小时-24小时）
- 转化期：从"发作"到"完全丧尸化"多久？（几分钟-几小时）
- 个体差异：老人/小孩/体弱者转化更快？

### 感染判定（必须有规则）
- 被咬一口 = 必死？还是有概率？
- 能否通过截肢阻止感染？
- 有没有"免疫者"？概率多少？
```

**经典设定参考**:
```markdown
## 《行尸走肉》感染规则
- 所有人类都已携带病毒（死后自动变丧尸）
- 被咬只是加速死亡（高烧致死），不是感染源
- 只有破坏大脑才能彻底杀死丧尸
- 规则简单、一致、好记

## 《生化危机》感染规则
- T病毒通过咬伤传播
- 感染后数小时内转化
- 不同体质变异不同（普通丧尸/舔食者/暴君）
- 有"等级"概念，威胁可以升级
```

---

### 技巧 C: 丧尸分级与威胁升级
丧尸不能一直是一种形态，需要有等级差异制造"威胁升级"。

**丧尸分级模板**:
```markdown
## 丧尸等级体系

### 普通丧尸（Lv.1）
- 特征：行动迟缓、无智慧、数量多
- 弱点：头部、火、噪音吸引
- 威胁：单个无威胁，成群危险
- 数量：占总数90%以上

### 变异丧尸（Lv.2）
- 特征：速度更快/力量更大/特殊能力
- 类型：
  - 奔跑者：速度极快，类似狂犬病
  - 巨型者：体型庞大，防御力高
  - 爬行者：可以爬墙，攻击方式诡异
- 弱点：各不相同，需要针对性战斗
- 数量：占总数5-8%

### 精英丧尸（Lv.3）
- 特征：有一定智慧，会设伏/包抄
- 类型：
  - 指挥者：可以指挥低级丧尸
  - 特殊感染者：有独特攻击方式（喷酸/自爆/隐身）
- 弱点：需要团队配合才能击杀
- 数量：占总数1-2%

### 丧尸王（Lv.4）
- 特征：接近人类智慧，有自己的领地
- 能力：指挥尸群、学习人类战术
- 弱点：极少，需要主角团全力击杀
- 数量：极其稀有，每个区域最多1-2只
```

## 2. 丧尸弱点与战斗体系

### 技巧 A: 弱点设计的"规则感"
丧尸弱点必须有明确规则，不能"想怎么杀就怎么杀"。

**弱点规则表**:

| 弱点 | 效果 | 限制 | 战术价值 |
|------|------|------|---------|
| **大脑** | 彻底死亡 | 必须精准命中头部 | 近战首选，需要训练 |
| **火焰** | 彻底死亡 | 可能引燃周围环境 | 对群尸有效，有副作用 |
| **脊椎** | 失去行动力 | 不算"杀死"，会再生 | 紧急情况的权宜之计 |
| **心脏** | 暂时停止 | 数分钟后恢复 | 需要连续攻击 |
| **噪音** | 吸引注意力 | 不致命，只是引导 | 战术层面的诱饵 |

**战斗场景设计**:
```markdown
## 丧尸战斗场景模板

场景：主角团被困在超市，外面有200只普通丧尸

### 方案A：正面对抗（不推荐）
- 问题：弹药不够、体力消耗大、有伤亡风险
- 结果：可能全灭

### 方案B：声东击西（推荐）
- 步骤：
  1. 在超市后门放一个定时收音机（吸引丧尸）
  2. 从前门悄悄撤离
  3. 丧尸被声音吸引，集中到后门
- 优势：零伤亡、低消耗
- 风险：需要精确计时，有丧尸可能没被吸引

### 方案C：利用环境（创造性）
- 步骤：
  1. 在超市门口倒油
  2. 引丧尸进入
  3. 点火焚烧
- 优势：一次性解决大量丧尸
- 风险：火势可能失控、引来更多丧尸
```

### 技巧 B: 丧尸的"非致命"威胁
丧尸不只是"咬死人"，还有很多间接威胁。

**间接威胁清单**:
```markdown
## 丧尸的间接威胁

### 信息威胁
- 丧尸的存在让人类无法正常通讯
- 无线电会被丧尸的"嘶吼"干扰（设定可选）
- 夜间无法使用灯光（会吸引丧尸）

### 心理威胁
- 丧尸可能是曾经的亲人/朋友
- 长期面对丧尸导致心理创伤
- "我是不是也会变成那样？"的恐惧

### 资源威胁
- 丧尸占据了很多资源点（超市、医院、军火库）
- 获取资源必须先清理丧尸
- 丧尸的尸体污染水源和土地

### 社会威胁
- 丧尸潮导致人口大规模死亡
- 社会秩序崩塌
- 人类内部矛盾激化（争夺资源）
```

## 3. 丧尸的行为模式

### 技巧 A: 丧尸的"本能"设定
丧尸虽然没有智慧，但应该有可预测的行为模式。

**丧尸行为模式表**:

| 行为 | 触发条件 | 表现 | 战术利用 |
|------|---------|------|---------|
| **趋声性** | 声音 | 向声源移动 | 用噪音制造诱饵 |
| **趋光性** | 强光 | 向光源聚集 | 夜间用火把引开 |
| **趋热性** | 体温 | 向活人靠近 | 无法完全规避 |
| **群聚性** | 数量多 | 自然形成尸群 | 可以引导尸群方向 |
| **领地性** | 丧尸王 | 固定区域巡逻 | 可以避开领地 |

**行为模式写作示例**:
```markdown
## 丧尸行为模式示例

场景：主角团需要穿过一个丧尸密集的街区

### 观察阶段
- 主角观察到丧尸的移动规律
- 发现丧尸白天行动迟缓，夜晚活跃
- 发现丧尸对声音最敏感，对光线次之

### 制定计划
- 选择白天行动（丧尸迟缓）
- 准备多个噪音诱饵（定时闹钟）
- 规划安静的路线（避开碎玻璃、金属等会发出声音的东西）

### 执行阶段
- 先在远处放置噪音诱饵
- 丧尸被吸引，街区出现空隙
- 主角团快速安静通过
- 意外：一个队员踩到易拉罐，声音引来几只丧尸
- 紧急处理：近战无声击杀
```

### 技巧 B: 丧尸潮——末世的"天灾"
丧尸潮是末世小说的经典高潮场景。

**丧尸潮设计模板**:
```markdown
## 丧尸潮设计要素

### 触发条件
- 季节性迁徙（类似动物迁徙）
- 被大规模声音/光线吸引
- 丧尸王的指挥
- 自然灾害驱赶（地震、洪水）

### 规模分级
- 小型尸潮：数百只，可以防御
- 中型尸潮：数千只，需要撤离
- 大型尸潮：数万只，只能逃命
- 超级尸潮：数十万只，改变区域格局

### 应对策略
- 防御：加固基地、设置陷阱、储备弹药
- 撤离：提前预警、规划路线、带走物资
- 引导：利用噪音/光线改变尸潮方向
- 分割：利用地形将尸潮分成小股
```

## 常见错误

1. **丧尸设定前后矛盾**: 前期说丧尸怕火，后期又说火烧不死。必须建立规则表并严格遵守。

2. **丧尸威胁忽大忽小**: 剧情需要时丧尸很厉害，不需要时随便杀。威胁等级应该有稳定的基准线。

3. **忽略丧尸尸体处理**: 大量丧尸死亡后，尸体怎么处理？会腐烂、会污染、会引发瘟疫。这是重要的情节素材。

4. **丧尸没有行为逻辑**: 丧尸出现得太随机，没有规律可循。应该有可预测的行为模式，让主角的"策略"有意义。

5. **感染机制不一致**: 被咬有时会感染有时不会，规则不清晰。必须提前定好规则并执行到底。

## 自查清单

- [ ] 丧尸起源是否明确？是病毒、灵气还是其他？
- [ ] 感染机制是否有清晰的规则？途径、时间、判定标准？
- [ ] 丧尸是否有分级？不同等级的威胁差异是否明显？
- [ ] 丧尸弱点是否有规则？不是想怎么杀就怎么杀？
- [ ] 丧尸是否有可预测的行为模式？主角可以利用这些模式？
- [ ] 是否有"丧尸潮"等大规模威胁场景？
- [ ] 丧尸设定是否全书一致？有没有前后矛盾？
- [ ] 丧尸尸体的处理是否有交代？
