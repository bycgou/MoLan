# 末世生存指南

> **核心原则**: 生存是末世小说的第一驱动力。真实的生存压力 = 合理的资源稀缺 + 持续的外部威胁 + 艰难的道德抉择。

---

## 1. 生存资源体系设计

### 技巧 A: 资源分类与稀缺度阶梯
末世中资源不是"有或无"，而是按稀缺度分层递进。

**资源稀缺度阶梯表**:

| 阶段 | 时间线 | 稀缺资源 | 充足资源 | 生存状态 |
|------|--------|---------|---------|---------|
| **混乱期** | 末世第1-7天 | 药品、武器 | 食物、水（超市残留） | 短期能活，秩序崩塌 |
| **崩溃期** | 第2周-第1月 | 饮用水、燃油 | 干粮（逐渐耗尽） | 团伙争夺，弱肉强食 |
| **寒冬期** | 第2-6月 | 食物、电力、弹药 | 几乎没有 | 大规模死亡，文明崩塌 |
| **重建期** | 半年后 | 种子、建材、人才 | 水源（净化后） | 有组织生存，基地化 |

**写作要点**:
```
✅ 第一章就要让读者感受到"物资不够用"
✅ 不要一次性写光所有物资，要分阶段递进
✅ 资源争夺是推动剧情的核心引擎
```

---

### 技巧 B: 水源危机——最被低估的生存要素
很多末世小说忽略了水的重要性。人可以三天不喝水就会死亡，水源比食物更紧迫。

**水源设计清单**:
```markdown
## 水源危机情节模板

第1阶段：自来水断供
- 末世第3天，城市供水系统瘫痪
- 住户开始囤积桶装水、接雨水

第2阶段：水源争夺
- 超市瓶装水被抢光
- 河流/湖泊成为兵家必争之地
- 有人开始用暴力垄断水源

第3阶段：净化难题
- 河水被丧尸尸体污染
- 需要净水设备或净水药片
- 净水知识成为关键生存技能

第4阶段：水源基地化
- 建立净水站成为基地核心功能
- 控制水源 = 控制人口 = 控制权力
```

### 技巧 C: 食物链崩塌与替代方案
末世不只是"没饭吃"，而是整个食物链崩塌。

**食物来源演变表**:

| 阶段 | 主要食物 | 风险 | 情节价值 |
|------|---------|------|---------|
| **超市搜刮** | 罐头、方便面、饼干 | 其他幸存者争夺 | 展示初期混乱 |
| **野外采集** | 野菜、野果、昆虫 | 有毒/被丧尸包围 | 展示生存技能 |
| **狩猎捕鱼** | 野兔、鱼、鸟 | 武器消耗、体力消耗 | 展示团队配合 |
| **农业种植** | 土豆、红薯、小麦 | 周期长、需要守护 | 展示重建希望 |
| **养殖畜牧** | 鸡、羊、兔子 | 饲料来源、疫病 | 展示文明回归 |

**经典桥段**:
> 主角团搜刮了一个便利店，找到三箱方便面和两箱矿泉水。还没来得及高兴，就听到外面传来脚步声——另一伙幸存者也盯上了这里。食物在末世不是"物资"，是"命"。

## 2. 环境威胁设计

### 技巧 A: 丧尸以外的致命威胁
末世的威胁不只是丧尸，环境本身就在杀人。

**环境威胁清单**:
```markdown
## 末世环境威胁分级

### 气候威胁
- 核冬天：核战后气温骤降，农作物绝收
- 酸雨：工业设施无人维护，有毒气体泄漏
- 极端天气：暴雪、酷暑、龙卷风（无预警系统）

### 疾病威胁
- 伤口感染：没有抗生素，一个小伤口可能致命
- 瘟疫传播：尸体处理不当引发瘟疫
- 饮水污染：霍乱、痢疾等消化道疾病

### 基础设施崩塌
- 电力中断：冰箱食物腐烂、冬季无取暖
- 通讯中断：无法获知外界信息，孤立无援
- 交通瘫痪：道路被毁、车辆没油、桥梁断裂
```

### 技巧 B: 季节变化的叙事功能
季节不只是背景，而是推动剧情的工具。

**季节叙事对照表**:

| 季节 | 生存挑战 | 叙事功能 | 经典场景 |
|------|---------|---------|---------|
| **冬季** | 取暖、食物匮乏 | 高压生存、团队考验 | 暴雪中守夜、分食最后一块饼干 |
| **春季** | 瘟疫、洪水 | 希望与危机并存 | 播种的希望vs洪水的威胁 |
| **夏季** | 缺水、丧尸活跃 | 高强度战斗 | 烈日下突围、水源争夺战 |
| **秋季** | 收获、囤积 | 短暂和平、阴谋酝酿 | 丰收节vs背叛者的暗手 |

**写作提示**:
```
✅ 用季节变化制造"时间紧迫感"（冬天快来了，必须囤粮）
✅ 季节转换时安排重大事件（入冬前的最后争夺）
✅ 避免"四季如春"——末世的天气应该更极端
```

## 3. 生存技能与知识体系

### 技巧 A: 实用生存技能清单
主角需要掌握的技能应该有层次、有逻辑。

**技能树设计**:
```markdown
## 末世生存技能树

### 基础生存（普通人能学会）
- 生火：钻木取火、放大镜聚光、电池短路
- 净水：煮沸、简易过滤器、净水片
- 包扎：止血、骨折固定、伤口缝合
- 辨向：太阳定位、北极星、树木年轮

### 进阶生存（需要一定知识）
- 狩猎：陷阱制作、弓箭使用、追踪技巧
- 种植：选种、堆肥、防虫、轮作
- 机械：汽车维修、发电机维护、水泵修理
- 医疗：草药识别、简易手术、疫病防治

### 高级生存（专业人才）
- 建筑：防御工事、房屋加固、水利工程
- 电气：太阳能板安装、电路维修、蓄电池
- 化工：火药制造、酒精蒸馏、净水剂合成
- 军事：战术指挥、武器维护、防御部署
```

---

### 技巧 B: 知识传承的紧迫感
末世中"会什么"比"有什么"更重要。

**知识价值排序**:
```markdown
## 末世知识价值排行榜

第1名：医疗知识（外科/内科/草药）
- 原因：人会受伤、生病，医生是最稀缺的人才
- 情节：一个外科医生比一箱黄金更值钱

第2名：农业知识（种植/养殖/育种）
- 原因：长期生存必须自给自足
- 情节：老农民的种地经验成为基地核心机密

第3名：工程知识（建筑/电气/机械）
- 原因：基地建设、设备维护都需要
- 情节：工程师是基地建设的"总设计师"

第4名：军事知识（战术/武器/防御）
- 原因：保护基地、对抗敌对势力
- 情节：退伍军人成为基地的"守护者"
```

## 常见错误

1. **物资无限刷新**: 主角永远能搜刮到食物和武器，没有真正的匮乏感。正确做法是让每次搜刮都有风险，物资越来越少。

2. **生存技能轻描淡写**: 主角突然会开枪、会做饭、会修车，没有任何铺垫。应该在末世前就埋下伏笔（退伍兵、农村出身、理工科背景）。

3. **环境威胁消失**: 一旦有了基地，就不再提天气、疾病、基础设施问题。环境威胁应该贯穿全文。

4. **食物来源太轻松**: 主角团从没饿过肚子，每次都能找到吃的。应该有"断粮"的危机情节。

5. **忽视心理健康**: 末世中人会恐惧、焦虑、崩溃、绝望。只写肉体生存不写精神状态是不完整的。

## 自查清单

- [ ] 资源是否有明确的稀缺度阶梯？不是一开始就什么都有？
- [ ] 水源危机是否有独立的情节线？不是只提一句"没水了"？
- [ ] 食物来源是否有阶段性变化？不是一直靠搜刮超市？
- [ ] 环境威胁是否独立于丧尸存在？天气、疾病、基础设施是否都有涉及？
- [ ] 季节变化是否影响了剧情走向？不是四季如春？
- [ ] 主角的生存技能是否有铺垫？不是突然变成全能战士？
- [ ] 是否有"断粮/断水"的危机情节？不是一直物资充足？
- [ ] 角色的心理状态是否有描写？不是所有人都钢铁意志？
