# 仙界世界设定 (Immortal Realm Worldbuilding)

> **核心原则**: 仙侠世界的魅力在于"层次感"——凡人仰望仙人，仙人仰望天道。每一层世界都应该有独特的规则、生态和冲突。

---

## 1. 世界的三层架构

仙侠世界通常由三个大的层次构成：

```
天界（仙人居所）
  ↑ 飞升
修真界（修士争锋）
  ↑ 灵气隔绝
凡人界（凡人国度）
```

### 凡人界设定

```
**特点**:
- 灵气稀薄，修士极少
- 凡人不知仙人存在，或只当是传说
- 有王朝、江湖、世俗势力
- 偶有低阶修士下山历练

**写作用途**:
- 主角出身地，制造"井底之蛙"的初始视角
- 凡人视角仰望修真界，制造向往感
- 后期主角回归凡人界，制造"沧海桑田"的感慨
```

### 修真界设定

```
**特点**:
- 灵气充沛，宗门林立
- 修士为主导力量，凡人是底层
- 有坊市、拍卖会、秘境等特色场景
- 势力格局复杂，正魔对立

**区域划分**:
- 东域：正道宗门聚集地
- 西荒：妖兽横行的蛮荒之地
- 南疆：毒虫瘴气、巫蛊传承
- 北冥：苦寒之地，隐藏上古遗迹
- 中州：最繁华，顶级宗门驻扎
```

### 仙界设定

```
**特点**:
- 仙灵之气，修炼速度倍增
- 仙人为主导，修士是"凡人"
- 有天庭/仙宫等管理机构
- 等级森严，仙人之间也有高低贵贱

**仙界分区**:
- 凡仙域：刚飞升的真仙
- 金仙域：金仙以上方可进入
- 天庭：管理机构，有仙官仙将
- 禁地：连仙人也不敢踏足的区域
```

## 2. 灵气与灵脉系统

### 灵气浓度等级

```
灵气枯竭区：凡人界，几乎无灵气（修士在此如鱼离水）
灵气稀薄区：偏远之地，勉强可以修炼
灵气正常区：宗门驻地标准
灵气浓郁区：顶级宗门、洞天福地
灵气液化区：秘境核心，灵气浓到可以看见
仙灵之气区：仙界，本质不同于凡间灵气
```

### 灵脉设定

```
灵脉是大地中灵气汇聚的经络，类似人体经脉。

**灵脉等级**:
- 下品灵脉：可支撑筑基期修士修炼
- 中品灵脉：可支撑金丹期修士修炼
- 上品灵脉：可支撑元婴期修士修炼
- 极品灵脉：可支撑化神期修士修炼
- 仙脉：仅仙界存在，支撑仙人修炼

**写作用途**:
- 宗门争夺灵脉 = 核心利益冲突
- 灵脉枯竭 = 宗门衰落的伏笔
- 发现新灵脉 = 重大剧情转折
```

## 3. 秘境与遗迹系统

### 秘境类型

| 类型 | 特点 | 危险等级 | 奖励等级 |
|------|------|---------|---------|
| **天然秘境** | 天地自然形成，内有灵药 | 低-中 | 中 |
| **上古遗迹** | 大能陨落后的洞府 | 高 | 极高 |
| **小世界** | 独立于主世界的微型世界 | 极高 | 极高 |
| **试炼秘境** | 宗门设置的考验之地 | 可控 | 按成绩分配 |
| **天地异象** | 特定时间开启的临时秘境 | 不定 | 极高 |

### 秘境描写模板

```
## 秘境：太虚幻境
**开启条件**: 每百年开启一次，持续七日
**进入限制**: 金丹期以下
**内部规则**:
- 灵气浓郁，是外界的十倍
- 内有幻阵，会制造心魔幻象
- 越深入，机缘越大，危险也越大
- 第七日自动传送出来

**核心宝物**:
- 太虚灵果（服用后可直接突破一个小境界）
- 上古功法残篇
- 大能遗留的法宝碎片

**描写要点**:
- 入口：空间裂缝撕开，露出一片混沌
- 内部：青山绿水却暗藏杀机
- 深处：空间扭曲，法则混乱
```

## 4. 天地规则与大道法则

### 大道法则体系

```
基础法则（修士可感悟）：
- 金木水火土：五行大道
- 风雷冰暗光：元素大道
- 剑道、刀道、拳道：武道法则

高阶法则（仙人方可触及）：
- 时间大道
- 空间大道
- 因果大道
- 轮回大道
- 毁灭大道
- 创生大道

至高法则（超越仙人）：
- 天道（万物运行的根本规则）
- 命运大道（不可捉摸，连圣人也无法完全掌控）
```

### 法则感悟的描写

```
苏尘盘坐于瀑布之下，感受着水的流动。
起初，他只听到轰鸣的水声。
渐渐地，他"看"到了水的轨迹——
每一滴水都在遵循某种规律，从高到低，从聚到散。
"水善利万物而不争……"
他心中一道灵光闪过。
——水之大道，入门。
```

## 5. 生态与异族设定

### 修真界生态

```
**灵兽**:
- 低阶灵兽：相当于练气-筑基期修士
- 中阶灵兽：相当于金丹-元婴期
- 高阶灵兽：相当于化神期以上
- 神兽（龙、凤、麒麟）：仙人级别

**妖族**:
- 妖兽开智化形后即为妖族
- 妖族有自己的势力和领地
- 人妖关系可以是合作、对抗或共存

**鬼修/魔修**:
- 鬼修：死后魂魄不散，以鬼身修炼
- 魔修：修炼魔功，以吞噬他人修为为主
- 与正道修士天然对立
```

### 异族设定

```
**魔族**:
- 来自魔界，与仙界对立
- 修炼魔气，与灵气本质不同
- 周期性入侵修真界（万年一次大劫）

**古族**:
- 上古遗族，血脉强大
- 天生神通，不需要刻意修炼
- 数量稀少，但个体实力极强

**域外天魔**:
- 来自世界之外的存在
- 无形无质，专门引诱修士产生心魔
- 是渡劫时最大的威胁
```

## 6. 世界设定的常见问题

### 问题 1：世界太大，写到后期失控
```
解决：采用"洋葱式"展开。
      第一层：主角所在的小国/小宗门
      第二层：所在区域/大宗门
      第三层：整个修真界
      第四层：仙界
      每一层都是一个完整的"小世界"，有独立的势力格局。
```

### 问题 2：设定堆砌，喧宾夺主
```
问题：用大段文字介绍世界设定，读者昏昏欲睡。
解决：设定要"用"不要"讲"。
      不要写"修真界有五大宗门，分别是……"
      要写"苏尘踏入天剑宗山门，只见万剑悬空，剑气冲霄。"
      ——读者自然知道天剑宗很厉害。
```

### 问题 3：前后设定矛盾
```
解决：建立"世界设定文档"，记录以下内容：
      - 地图（手绘或文字描述）
      - 势力分布
      - 灵脉/灵气分布
      - 已出场的地点描述
      每次写新场景前先查阅。
```
