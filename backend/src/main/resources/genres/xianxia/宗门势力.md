# 宗门与势力设定 (Sect and Faction Politics)

> **核心原则**: 宗门是仙侠小说的"社会"。好的宗门设定 = 清晰的等级结构 + 利益纠葛 + 人物关系网 + 与主角成长的深度绑定。

---

## 1. 宗门架构设计

### 标准宗门架构

```
宗主（一人）
├── 太上长老（退隐的前任宗主/老祖，不问俗事，只在宗门生死存亡时出手）
├── 长老会（3-7人）
│   ├── 大长老（日常决策者）
│   ├── 执法长老（掌管宗规）
│   ├── 传功长老（传授功法）
│   ├── 外事长老（对外交涉）
│   └── 内务长老（资源分配）
├── 执事堂（中层管理）
│   ├── 内门执事
│   ├── 外门执事
│   └── 杂务执事
├── 弟子层级
│   ├── 核心弟子（宗主/长老亲传，3-10人）
│   ├── 内门弟子（天赋出众，50-200人）
│   ├── 外门弟子（普通资质，数百至数千人）
│   └── 杂役弟子（底层，负责杂务）
└── 附属势力
    ├── 附属家族
    ├── 附属小宗门
    └── 凡人国度
```

### 宗门描写的层次感

```
**写法要点**：不要一次性把架构全部倒出来，而是通过主角的视角逐步展开。

第一层（入门时）：
苏尘站在青云宗山门前，只见白云缭绕，仙鹤翱翔。
"这就是……修仙宗门？"
他只是外门弟子，连山门内的景象都不清楚。

第二层（成为内门弟子后）：
进入内门，苏尘才知道——
青云宗有七座主峰，每座主峰由一位长老坐镇。
而宗主，据说已经化神期大圆满……

第三层（成为核心弟子后）：
"你知道宗门为什么叫'青云'吗？"
传功长老意味深长地说：
"因为宗门下方，镇压着一条上古青龙……"
```

## 2. 宗门等级体系

### 宗门等级划分

```
**不入流宗门**：
- 最强者：筑基期
- 弟子数量：数十人
- 占据一个小山头
- 地位：修真界底层

**三流宗门**：
- 最强者：金丹期
- 弟子数量：数百人
- 占据一条灵脉
- 地位：勉强立足

**二流宗门**：
- 最强者：元婴期
- 弟子数量：数千人
- 占据数条灵脉
- 地位：区域势力

**一流宗门**：
- 最强者：化神期
- 弟子数量：上万人
- 占据大型灵脉
- 地位：一方霸主

**顶级宗门/圣地**：
- 最强者：炼虚期以上
- 弟子数量：数万
- 占据洞天福地
- 地位：超然物外
```

### 宗门等级与主角成长的对应

```
**设计思路**：主角的宗门等级，应该与主角当前境界匹配。

- 练气-筑基期：主角在三流宗门
- 金丹期：主角进入二流宗门或原宗门升级
- 元婴期：主角进入一流宗门
- 化神期：主角接触顶级势力
- 化神期以上：主角超脱宗门，自立门户或行走天下

**经典套路**：
主角从小宗门起步 → 被大宗门看中 → 进入大宗门 → 在大宗门中崛起 → 最终超越宗门
```

## 3. 宗门内部政治

### 派系斗争

```
**常见的派系划分**：
1. 宗主派 vs 长老派（权力之争）
2. 外来弟子 vs 本土弟子（资源之争）
3. 天才弟子 vs 平庸弟子（地位之争）
4. 保守派 vs 激进派（路线之争）

**示例**：
青云宗内部，两大派系明争暗斗——
宗主一脉：主张对外开放，与其他宗门合作。
大长老一脉：主张保守自守，独占资源。

苏尘作为宗主的亲传弟子，自然被打上了"宗主派"的标签。
大长老的弟子，处处与他作对……
```

### 资源分配冲突

```
**核心矛盾**：资源有限，人人都想多分。

**常见的资源冲突**：
- 灵石分配：内门弟子每月100块，外门弟子每月10块
- 功法传承：核心功法只传核心弟子
- 丹药配额：突破瓶颈的丹药数量有限
- 秘境名额：秘境进入人数有上限

**写作用途**：资源分配不公，是制造内部冲突的最佳手段。

**示例**：
"凭什么他能进内门，我不能？"
"因为他是单灵根，你是三灵根。"
"就因为灵根？我为宗门出生入死十年！"
"这就是修真界的规则。"
——这段对话，比任何说教都更能展示修真界的残酷。
```

## 4. 宗门外部关系

### 宗门关系类型

```
**盟友宗门**：
- 共同对抗强敌
- 资源互通有无
- 弟子交流切磋
- 联姻巩固关系

**敌对宗门**：
- 争夺灵脉/资源
- 历史恩怨
- 理念冲突（正魔之争）
- 弟子间的私仇上升为宗门战争

**中立势力**：
- 商盟（只做生意，不站队）
- 散修联盟（松散组织）
- 上古世家（超然物外）

**附属势力**：
- 依附大宗门的小宗门/家族
- 定期上贡资源
- 换取大宗门的庇护
```

### 宗门大比

```
**用途**：展示实力、争夺资源、推动剧情。

**设定模板**：
## 百年宗门大比
**参与宗门**：东域八大宗门
**比试规则**：
- 金丹期以下弟子参加
- 个人赛 + 团体赛
- 前三名获得秘境进入名额

**写作要点**：
- 主角在大比中崭露头角
- 遭遇其他宗门的天才弟子
- 可能有阴谋（暗中下毒、安排强敌）
- 大比结果影响宗门排名和资源分配
```

## 5. 特色势力设定

### 散修势力

```
**特点**：
- 无宗门约束，自由自在
- 资源获取全靠自己
- 实力参差不齐
- 数量庞大，但组织松散

**散修聚集地**：
- 坊市：散修交易之所
- 散修联盟：临时组织，共同对抗宗门压迫
- 黑市：地下交易，什么都有卖

**写作用途**：散修视角可以展示修真界的"底层生态"。
```

### 魔道势力

```
**特点**：
- 修炼功法诡异，以吞噬/杀戮为修炼手段
- 被正道视为异端
- 实力不弱于正道
- 内部同样有等级和规矩

**魔道宗门架构**：
- 魔主（相当于宗主）
- 魔将（相当于长老）
- 魔众（相当于弟子）

**写作要点**：魔道不是纯粹的反派，可以有自己的理念和苦衷。
```

### 上古世家

```
**特点**：
- 血脉传承，天赋异禀
- 底蕴深厚，有上古法宝和功法
- 数量稀少，不轻易出世
- 出世则震动修真界

**示例**：
"你听说过'姬家'吗？"
"上古姬家？那个传说中的……"
"没错。据说姬家老祖，是上古大神的后裔。
他们家随便出来一个弟子，都能横扫同阶。"
"这么厉害？"
"厉害？他们家化神期的老祖有三位。你觉得呢？"
```

## 6. 宗门描写的具体技巧

### 山门描写

```
**好的山门描写应该传达**：
- 宗门的实力（建筑规模、灵气浓度）
- 宗门的气质（威严、飘逸、诡异）
- 主角的心理（敬畏、向往、不安）

**示例（正道宗门）**：
青云宗山门，九百九十九级白玉阶梯直通云端。
阶梯两侧，古松参天，仙鹤盘旋。
山门之上，"青云"二字龙飞凤舞，据说出自祖师亲笔。
每走一步，苏尘都感到灵气更加浓郁。
走到最后一级时，他几乎要窒息——
不是恐惧，是灵气太浓了。

**示例（魔道宗门）**：
血魔宗山门，两根百丈高的白骨柱耸立。
柱上缠绕着血色锁链，锁链尽头悬挂着……人骨灯笼。
空气中弥漫着淡淡的血腥气。
"欢迎来到血魔宗。"引路的魔修咧嘴一笑。
苏尘后背发凉。
```

### 长老形象塑造

```
**常见长老类型**：
1. 慈祥型：对弟子关爱有加（传功长老）
2. 严厉型：铁面无私（执法长老）
3. 阴沉型：城府极深，别有用心（反派长老）
4. 疯癫型：不拘小节，实力深不可测（隐世老祖）
5. 势利型：看人下菜碟（制造冲突的工具人）

**示例**：
执法长老周身散发着寒意。
"违反宗规者，杖责一百，废去修为，逐出宗门。"
他的目光扫过在场弟子。
没有人敢与他对视。
——这就是执法长老的威严。
```

## 7. 宗门势力设定的常见错误

### 错误 1：宗门太扁平
```
问题：宗门只有"宗主+长老+弟子"三层，没有细节。

解决：增加中层（执事）、底层（杂役）、附属势力、派系等层次。
      让宗门像一个真正的"小社会"。
```

### 错误 2：正魔对立太简单
```
问题：正道都是好人，魔道都是坏人。

解决：正道中有伪君子，魔道中有真性情。
      用灰色地带代替黑白分明。
```

### 错误 3：宗门只是背景板
```
问题：宗门存在感极弱，只是主角修炼的地方。

解决：让宗门成为剧情的推动者——
      宗门大比、宗门战争、宗门内斗、宗门衰落……
      主角的成长与宗门的命运紧密相连。
```

## 8. 宗门势力自检清单

- [ ] 宗门是否有清晰的等级架构？
- [ ] 宗门内部是否有派系和利益冲突？
- [ ] 宗门外部关系是否丰富（盟友、敌人、中立）？
- [ ] 宗门等级是否与主角境界成长匹配？
- [ ] 是否有特色势力（散修、魔道、世家）？
- [ ] 宗门描写是否通过主角视角自然展开？
- [ ] 是否避免了"正道全好、魔道全坏"的脸谱化？
- [ ] 宗门是否真正参与了剧情推动？
