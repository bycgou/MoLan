# 电竞描写 (Esports Scene Writing)

> **核心原则**: 电竞文的战斗不在刀光剑影，而在键盘鼠标之间。好的电竞描写 = 让不懂游戏的读者也能感受到紧张 + 让懂游戏的读者觉得专业。

---

## 1. 比赛场景的基础结构

### 标准电竞场景四段式

**第一段：赛前铺垫（10-15%篇幅）**
```
作用: 建立紧张感，交代对局意义

要素:
- 比赛性质（常规赛/季后赛/决赛/世界赛）
- 双方实力对比（谁是热门，谁是冷门）
- 主角的心理状态（紧张/兴奋/压力/复仇心态）
- 观众/解说/队友的反应

示例:
"大屏幕上，两支战队的队标并列而立。
'STAR vs 暴风——三局两胜，胜者晋级决赛！'
解说台上的声音有些颤抖，因为没有人想到暴风能走到这一步。
而暴风的中单选手林北，正低头调整着鼠标DPI。
他的手指很稳。"
```

**第二段：对局过程（60-70%篇幅）**
```
作用: 核心战斗描写，节奏要有起伏

节奏控制:
- 开局（试探）: 双方互相摸底，气氛紧张
- 中期（交锋）: 第一波团战爆发，局势开始倾斜
- 高潮（逆转）: 主角打出神级操作，扭转战局
- 收尾（决胜）: 一波定胜负，比赛结束

注意: 不要从头到尾都在打，要有"安静"的时刻——
补兵、走位、眼神交流，这些细节才是真实感的来源。
```

**第三段：关键操作特写（15-20%篇幅）**
```
作用: 全文最燃的部分，需要浓墨重彩

写法: 放慢时间流速，拆解操作细节（详见第3节）
```

**第四段：赛后余韵（5-10%篇幅）**
```
作用: 情感收束，承上启下

要素:
- 胜者/败者的反应
- 观众的欢呼或沉默
- 主角的心理变化
- 伏笔（下一场比赛/下一个对手）
```

## 2. 不同游戏类型的描写侧重

### MOBA类（类似英雄联盟）
```
核心描写点:
- 对线期的微操博弈（补刀、换血、视野控制）
- 团战中的技能释放顺序和站位
- 打野的节奏带动（Gank时机、资源争夺）
- 大龙/小龙等关键资源的团战

高频术语:
换血、补刀、Gank、反蹲、开团、切后排、拉扯、
视野差、经济差、推塔节奏、大龙逼团

示例:
"林北的妖姬一个W踩上去，QRE三连瞬间打出——
对面ADC的血条像被刀切了一样，从满血直接见底！
'秒了！林北秒了对面C位！'
解说台上的声音几乎破音。"
```

### FPS类（类似CS/瓦洛兰特）
```
核心描写点:
- 枪法对决（爆头、甩狙、压枪）
- 身法走位（急停、peek、架点）
- 战术执行（道具配合、转点、假动作）
- 残局处理（1vN的冷静判断）

高频术语:
爆头、甩狙、压枪、急停、peek、架点、
闪身、拉枪线、补枪、清角、回防、假打

示例:
"屏幕上只剩林北一个人。
对面还有三个。
'1v3，经济局，没甲没道具。'解说的声音压得很低。
林北没有犹豫。他切出刀，静步摸进了B包点。
第一个敌人背对着他。
刀光一闪。
'Doesn't even know.' 林北心里平静如水。"
```

### 大逃杀类（类似吃鸡/PUBG）
```
核心描写点:
- 落点选择和搜索路线
- 毒圈收缩时的转移决策
- 远距离对枪和近距离遭遇战
- 决赛圈的苟活与爆发

高频术语:
落点、搜物资、毒圈、转移、对枪、卡点、
架枪、拉烟、决赛圈、吃鸡、淘汰数

示例:
"决赛圈缩到了一片麦田里。
林北趴在草丛中，一动不动。
左边两个，右边一个，正前方还有一个满编队。
他在等。等他们先打起来。
枪声终于响了。三队混战！
林北抬起枪口，准星稳稳地套住了最后一个人的头。
'砰。'
'大吉大利，今晚吃鸡！'"
```

## 3. 关键操作的特写技巧

### 时间减速法

**原理**: 在关键时刻放慢叙事时间，让0.5秒的操作撑起一整段描写。

**标准模板**:
```
第1步: 操作触发（0.1秒）
"林北的食指按下了闪现键。"

第2步: 操作过程（0.2秒，用慢镜头展开）
"他的英雄化作一道残影，穿过墙壁——
这个闪现的角度，刁钻到连队友都没反应过来。
他的鼠标在空中划出一道弧线，准星瞬间锁定对面后排。"

第3步: 操作结果（0.1秒）
"QWER，四个技能在0.3秒内全部打出。
对面五个人的屏幕同时变成灰色。"

第4步: 反应（0.5秒后）
"全场沉默了整整两秒。
然后，解说台炸了。"
```

### 画面分切法

**原理**: 在团战中快速切换多个视角，制造紧迫感。

```
视角1（主角）:
"林北的手指在键盘上飞舞，技能栏几乎被按穿。"

视角2（队友）:
"辅助小李死死盯着屏幕，他的治疗术已经就绪——
'等一下，再等一下……就是现在！'"

视角3（对手）:
"对面的队长脸色骤变：'不对，他的走位——散开！快散开！'"

视角4（观众/解说）:
"全场观众已经站了起来。
大屏幕上的团战画面眼花缭乱，根本看不清谁在打谁。
但所有人都知道——这一波，要出大事了。"
```

## 4. 选手心理描写

### 赛场心理的三种状态

**状态一：Flow（心流）——最佳状态**
```
特征:
- 完全专注，感受不到外界
- 操作行云流水，不需要思考
- 时间感扭曲（感觉比赛只过了5分钟）

描写方式:
"林北不知道观众在喊什么。
他听不到解说的声音，甚至感觉不到手指在键盘上的触感。
他的世界里只剩下屏幕上的画面——
敌人的走位、技能的冷却、每一个可以利用的缝隙。
他不需要想，身体自己会动。"
```

**状态二：Tilt（心态爆炸）——最差状态**
```
特征:
- 被击杀后心态失衡
- 操作变形，越急越失误
- 开始甩锅队友，或者沉默不语

描写方式:
"第三次被单杀了。
林北的手开始发抖——不是紧张，是愤怒。
'我怎么会输给他？'
他开始做一些明知不该做的操作：强行换血、盲目追击、忽视小地图。
理智告诉他应该冷静，但手指不听使唤。"
```

**状态三：Clutch（绝境爆发）——最燃状态**
```
特征:
- 被逼入绝境时反而冷静下来
- 做出平时做不到的操作
- 逆转战局

描写方式:
"1v4。
所有人都觉得这局结束了。
但林北反而平静了下来——就像溺水的人突然停止挣扎。
他深吸一口气，手指放到了键盘上。
'能打。' 他在心里说。
接下来的10秒，他打出了职业生涯中最完美的一套操作。"
```

## 5. 团队配合的描写

### 指挥体系

```
队长/指挥: 做决策的人（"打大龙"、"转点"、"撤退"）
执行者: 听指挥操作的人（"收到"、"到位"）
自由人: 根据局势自行判断的人（"我绕后"）
信息员: 报点报信息的人（"对面打野在上路"）

写作要点:
- 好的团队不是每个人都强，而是配合默契
- 指挥的声音要果断，不能犹豫
- 执行要快，"收到"之后立刻行动
```

### 团战配合描写模板

```markdown
## 团战场景：暴风战队 vs STAR战队

**指挥**（队长林北）:
"打！辅助先手控！"

**执行**（辅助小李）:
小李的锤石Q技能脱手而出——
锁链精准命中对面ADC！

**跟进**（打野老张）:
老张的皇子EQ二连进场，大招盖下！
对面三人被框在了圈里！

**收割**（林北）:
"就是现在！"
林北的妖姬W进场，QRE连招瞬间打出——
三杀！

**解说反应**:
"配合！这就是配合！暴风战队的团战配合简直是教科书级别！"
```

## 6. 电竞描写自检清单

- [ ] **节奏感**: 是否有张有弛，不是全程高能？
- [ ] **专业度**: 术语使用是否准确，外行能看懂吗？
- [ ] **画面感**: 不懂游戏的读者能否脑补出画面？
- [ ] **心理描写**: 选手的情绪是否有层次变化？
- [ ] **团队感**: 是否只写了主角一个人，忽略了队友？
- [ ] **对手塑造**: 对手是否足够强，不是一个纯送的工具人？
- [ ] **解说/观众**: 是否用旁观者反应来烘托气氛？
- [ ] **时间感**: 关键操作是否有"慢镜头"特写？
