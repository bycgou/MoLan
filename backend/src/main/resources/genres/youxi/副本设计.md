# 副本设计 (Dungeon/Instance Design)

> **核心原则**: 副本是游戏小说的"试炼场"。好的副本设计 = 有清晰的阶段感 + 有需要动脑的机制 + 有让人屏息的BOSS战 + 有超出预期的奖励。

---

## 1. 副本的基础结构

### 标准副本三幕结构

**第一幕：入场与铺垫（10-15%篇幅）**
```
要素:
- 副本背景故事（为什么这个副本存在？）
- 队伍组成（谁来了？各怀什么目的？）
- 入场难度（需要什么条件才能进入？）
- 初始氛围（阴森/华丽/诡异/壮阔）

示例:
"副本入口是一扇石门，上面刻着古老的符文。
门缝里渗出幽绿色的光芒。
队伍频道里，辅助小李打字：'这个副本……上次全军覆没的是哪个公会来着？'
没有人回答。
林天推开石门。一股腐朽的气息扑面而来。"
```

**第二幕：推进与挑战（60-70%篇幅）**
```
要素:
- 小怪关卡（清怪、解谜、陷阱）
- 精英怪（需要配合才能击杀的强敌）
- 阶段BOSS（副本中段的拦路虎）
- 隐藏房间/支线（可选的额外挑战）

节奏控制:
小怪 → 小怪 → 精英怪 → 喘息 → 小怪 → 阶段BOSS → 喘息 → 最终BOSS
```

**第三幕：BOSS战与收尾（20-25%篇幅）**
```
要素:
- BOSS登场（要有压迫感）
- 战斗过程（机制复杂、需要配合）
- 关键时刻（差点灭团、极限通关）
- 奖励与发现（掉落物、剧情线索）
```

## 2. 副本机制设计

### 机制一：环境机制（场景本身是敌人）

**毒雾区**:
```
"副本的第三层弥漫着紫色毒雾。
每秒掉血50点。看起来不多，但队伍里最脆的法师只有8000血。
'最多待160秒。'林天算了一下。
'这个层的怪物分布……160秒不够清完。'
'那就别清。'他打字，'跑。'"
```

**地形陷阱**:
```
"地板突然裂开。
林天的反应很快——闪现。
但他身后的队友没来得及。
'我靠！这地板会动？！'
掉下去的人在队伍频道里打字：'下面有水……不对，是酸！掉血好快！'
林天往下看了一眼。
'别动，等我找路绕下去救你。'
'你最好快点，我的血只剩30%了。'"
```

**光线/视野限制**:
```
"副本里没有光源。
林天只能看到身前三米的范围。
'谁有照明技能？'
'我是法师，不是灯泡。'小李打字。
突然，黑暗中传来一声低吼。
所有人都停下了脚步。
'……它在哪？'
没有人知道。因为没有人看得见。"
```

### 机制二：解谜机制（需要动脑）

**密码/机关**:
```
"房间里有四根石柱，每根石柱上刻着一个符号。
门上写着一句话：'按正确顺序激活，门将开启。'
'什么顺序？'小李问。
林天看了看墙壁上的壁画。
壁画上画着四个场景：日出、正午、日落、午夜。
'太阳的位置。'他说，'从左到右，按太阳的位置排列。'
他依次激活了石柱。
门开了。"
```

**元素克制**:
```
"BOSS有四种形态：火、水、风、地。
每种形态只能被对应的元素克制。
'火形态用水技能打，水形态用风技能打……'
'等等。'小李打断他，'我们队伍里没有风系法师。'
林天沉默了三秒。
'那就用物理硬打。'
'物理打水系BOSS？伤害减半啊！'
'减半也得打。总不能退出去换个队友吧。'"
```

**时间限制**:
```
"副本中央有一个巨大的沙漏。
沙子流完的那一刻，所有人会被传送出副本。
三个小时的进度，全部归零。
'沙漏还剩多少？'
'47分钟。'
'最终BOSS还有30%血量。'
'够了。'林天打字，'全力输出，别管小怪了。'
'但小怪在打治疗啊！'
'治疗自己扛。我们DPS全打BOSS。'
小李：'……你认真的？'
'认真的。信我。'"
```

### 机制三：团队配合机制（需要默契）

**站位要求**:
```
"BOSS释放了一个技能：地裂。
以BOSS为圆心，向外扩散的环形伤害。
但每隔90度，有一个安全区。
四个人，四个安全区，一人一个。
'各自站位！'林天喊道。
'我在北！'
'东！'
'南！'
'西！'
地裂的冲击波从中心扩散——
四个人，全部站在安全区里。
完美。"
```

**职责分配**:
```
"这个BOSS需要三个人同时攻击三个弱点。
弱点在BOSS的左肩、右肩和背后。
'我打左肩。'林天说。
'我打右肩。'老张说。
'背后谁来？'
沉默。
背后是BOSS最危险的位置——它的尾巴会随机扫击。
'……我来。'小李打字，'但我只有一次机会。如果我死了，你们就放弃。'
'你不会死的。'林天说，'我在你旁边放了护盾。'
小李深吸一口气，绕到了BOSS背后。
'三、二、一——开！'"
```

## 3. BOSS战设计

### BOSS战的五个阶段

**阶段一：试探（100%-80%血量）**
```
作用: 让玩家熟悉BOSS的攻击模式
难度: 低
描写重点: BOSS的外形、攻击方式、技能前摇

示例:
"BOSS是一只巨大的石像鬼。
它第一次攻击是挥爪——前摇很明显，林天轻松躲开。
'普攻，伤害不高。'他在队伍频道里记录。
'注意，它的眼睛变红了——应该是要放技能！'
石像鬼张开嘴，一道射线喷出！
林天侧身闪避，射线擦着他的肩膀飞过。
'射线技能，直线型，可以躲。'"
```

**阶段二：加压（80%-50%血量）**
```
作用: 增加难度，引入新机制
难度: 中
描写重点: 队伍开始出现压力，需要配合

示例:
"石像鬼的血量降到75%时，它突然飞了起来。
'新阶段！'林天喊道。
石像鬼在空中盘旋，然后俯冲——
目标是队伍里血最少的法师小李！
'保护！'林天立刻对小李释放了护盾。
但护盾只能挡一次攻击。石像鬼又飞起来了。
'它会连续俯冲三次。'林天判断。
'三次？我的护盾冷却要10秒！'
'那就用走位躲。听我指挥——左、右、左！'"
```

**阶段三：危机（50%-20%血量）**
```
作用: 全文最紧张的部分，差点灭团
难度: 高
描写重点: 队伍陷入危机，需要极限操作

示例:
"BOSS的血量刚过50%，它的眼睛变成了深红色。
'全体后退！'林天喊道——但已经来不及了。
石像鬼释放了全屏AOE：石化凝视！
队伍里四个人，三个被石化了。
只剩下林天——因为他在最后一秒背对了BOSS。
'只有我了。'
他看了一眼队友的状态：石化持续15秒。
BOSS还有48%的血量。
15秒，一个人，打48%的血。
理论上不可能。
但林天没有犹豫。他冲了上去。"
```

**阶段四：绝境反击（20%-5%血量）**
```
作用: 主角秀操作的高光时刻
难度: 极高
描写重点: 极限操作、时间紧迫、队友陆续解控

示例:
"13秒。
林天的技能已经全部进入冷却。
他开始用普通攻击——一刀、两刀、三刀。
BOSS的血量：45%……44%……43%……
不够。远远不够。
'还有10秒。'他在心里数着。
就在这时——
'我解控了！'小李的声音从耳机里传来。
'我也是！'老张也醒了。
'全力输出！'林天吼道。
三个人同时开大——
BOSS的血量像雪崩一样往下掉：30%……20%……10%……"
```

**阶段五：终结（5%-0%血量）**
```
作用: 最后一击，胜利时刻
难度: 低（胜利在望）
描写重点: 最后一击的仪式感、胜利的喜悦

示例:
"BOSS的血量只剩3%。
它的动作开始变形——这是'狂暴'的前兆。
'要在它狂暴之前打死！'林天喊道。
'技能都在冷却！'
'我有一个终极技能——CD刚好转好。'
林天的屏幕亮起了金色的光芒。
他按下了R键。
一道光柱从天而降，贯穿了石像鬼的身体。
BOSS的血量归零。
石像鬼碎裂成无数石块，轰然倒塌。
屏幕中央浮现出一行金色文字：
'恭喜！深渊石像鬼已被击杀！'"
```

## 4. 副本奖励设计

### 奖励的层次感

```
基础奖励（必得）:
- 经验值（升级所需）
- 金币（购买物资）
- 副本代币（兑换装备）

稀有奖励（概率掉落）:
- 蓝色/紫色装备（提升战力）
- 稀有材料（制作高级物品）
- 技能书（学习新技能）

传说奖励（极低概率）:
- 橙色装备（改变玩法）
- 坐骑/宠物（炫耀道具）
- 隐藏任务线索（推动剧情）

首杀奖励（仅限第一次）:
- 专属称号（"深渊征服者"）
- 专属外观（限定皮肤）
- 大量经验/金币
```

### 奖励揭晓的写法

**普通掉落（一笔带过）**:
```
"BOSS倒下，掉落了一地物品。
林天快速扫了一眼：两件蓝装、一堆材料、300金币。
'垃圾。'他随手把装备分给了队友。"
```

**稀有掉落（重点描写）**:
```
"在那一堆灰色和蓝色的物品中，有一道紫色的光芒。
林天的鼠标移过去——
'深渊之刃（紫色·史诗）'
攻击力：244-387
特效：攻击时有15%概率触发'深渊裂斩'，对目标造成额外200%伤害
'……出货了。'他的声音有点发抖。"
```

**传说掉落（浓墨重彩）**:
```
"所有人都以为战斗结束了。
但BOSS碎裂的石块中，突然射出一道金色光芒！
所有人同时看到了系统公告——
'恭喜玩家[林天]获得全服首件传说装备：[石像鬼之心]！'
世界频道瞬间炸了。
'传说装备？？？'
'这游戏有传说装备？'
'多少钱？开价！'
林天没有理会频道里的消息。
他看着那件装备的属性，嘴角慢慢扬了起来。"
```

## 5. 副本难度曲线

### 难度递进设计

```
普通副本（入门）:
- 机制简单，走位躲技能即可
- 容错率高，死一次也能过
- 适合新手练习

精英副本（进阶）:
- 机制复杂，需要解谜
- 容错率中等，需要配合
- 适合固定队伍

噩梦副本（挑战）:
- 机制刁钻，需要研究
- 容错率低，一人失误全灭
- 适合高手挑战

地狱副本（极限）:
- 机制变态，需要完美配合
- 容错率为零，任何失误都致命
- 适合顶尖玩家冲记录
```

## 6. 副本设计自检清单

- [ ] **阶段感**: 副本是否有清晰的阶段划分（小怪→精英→BOSS）？
- [ ] **机制多样**: 是否只有打打杀杀，还是有解谜/环境/配合机制？
- [ ] **BOSS有层次**: BOSS战是否有多个阶段，不是站桩输出？
- [ ] **危机感**: 是否有"差点灭团"的紧张时刻？
- [ ] **配合需求**: 是否需要队友配合，不是一个人就能通关？
- [ ] **奖励有层次**: 是否有普通/稀有/传说的奖励梯度？
- [ ] **有隐藏内容**: 是否有隐藏房间、彩蛋、支线？
- [ ] **前后呼应**: 副本的背景故事是否和主线剧情有关联？
