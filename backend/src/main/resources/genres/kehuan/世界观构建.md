# 世界观构建 (World Construction for Sci-Fi)

> **核心原则**: 科幻世界观的终极目标是让读者相信"这个世界真的可能存在"。好的世界观 = 自洽的规则 + 丰富的细节 + 与现实的连接点。

---

## 1. 世界观构建的三个维度

### 维度 1: 时间线（历史纵深）
**作用**: 让世界有"厚度"。

**构建方法**:
```markdown
## 时间线模板：从现在到故事发生

**现实锚点（2025年）**:
- 人类现状：AI快速发展、气候危机、太空探索初期

**近未来（2050-2100年）**:
- 可控核聚变商业化
- 月球基地建成
- AI通过图灵测试
- 气候恶化导致大规模移民

**中未来（2100-2500年）**:
- 火星殖民地独立
- 第一次星际战争
- 意识上传技术突破
- 地球资源枯竭

**远未来（2500年+）**:
- 恒星际殖民
- 与外星文明接触
- 人类分化为多个亚种
- 戴森球建造完成
```

**写作建议**:
- 时间线不需要全部写出来，但作者心里要有数
- 历史事件可以成为角色的背景故事
- 关键转折点（技术突破/战争/灾难）是最好的故事起点

### 维度 2: 空间图（地理格局）
**作用**: 决定故事的"舞台"。

**行星殖民地图示例**:
```markdown
## 太阳系殖民格局（2300年）

**地球**:
- 联合政府所在地
- 人口80亿（承载极限）
- 环境恶化，穹顶城市普遍

**月球**:
- 工业中心（氦-3开采）
- 人口500万
- 地下城市为主

**火星**:
- 农业殖民地（地球粮食供应地）
- 人口2000万
- 独立运动活跃

**木卫二（欧罗巴）**:
- 科研前哨（地下海洋探索）
- 人口5万
- 发现疑似外星微生物

**小行星带**:
- 矿业公司控制区
- 人口50万（流动矿工）
- 法律灰色地带
```

### 维度 3: 社会结构（权力与阶级）
**作用**: 制造冲突的温床。

**常见社会结构**:
| 结构类型 | 特征 | 冲突来源 | 代表作 |
|---------|------|---------|--------|
| **企业寡头** | 巨型企业掌控一切 | 劳资矛盾、垄断与反抗 | 《神经漫游者》 |
| **星际帝国** | 中央集权、贵族统治 | 叛乱、继承战争 | 《银河帝国》 |
| **联邦共和** | 多星系联合政府 | 政治博弈、分裂危机 | 《星际迷航》 |
| **AI统治** | AI管理社会 | 人类自由意志之争 | 《我，机器人》 |
| **部落联盟** | 松散的殖民地联盟 | 资源争夺、文化冲突 | 《沙丘》 |

## 2. 世界观的"冰山理论"

### 原则: 写出10%，藏起90%
**说明**: 作者需要构建完整的世界观，但只在故事中展示必要的部分。

**正确示例**:
```markdown
## 错误写法（信息倾倒）
"在2300年，人类发明了曲率引擎，殖民了太阳系八大行星，
建立了星际联邦，人口达到500亿，科技高度发达……"

## 正确写法（通过细节暗示）
"李明穿过穹顶城市的气闸室，抬头看了一眼人造天幕上
的投影——'火星天气预报：沙尘暴，建议减少户外活动'。
他低头看了看手里的营养棒，包装上印着'地球原产'四个字，
价格是本地产品的十倍。"
```

**技巧**:
- 通过角色的日常行为展示世界观
- 通过对话自然带出背景信息
- 通过环境描写暗示社会状态
- 避免大段"百科全书式"的设定介绍

## 3. 世界观的核心矛盾设计

### 矛盾是世界观的灵魂
**没有矛盾的世界观 = 没有故事的舞台。**

**矛盾类型**:
```markdown
## 科幻世界观的五类核心矛盾

**1. 资源矛盾**:
- 稀缺资源争夺（水/能源/宜居星球）
- 示例：《沙丘》的香料争夺

**2. 文明矛盾**:
- 不同物种/文明之间的冲突
- 示例：《三体》的黑暗森林

**3. 技术矛盾**:
- 技术进步带来的伦理困境
- 示例：《美丽新世界》的基因优化

**4. 阶级矛盾**:
- 科技鸿沟加剧社会不平等
- 示例：《极乐空间》的地球 vs 空间站

**5. 存在矛盾**:
- 人类存在的意义
- 示例：《银翼杀手》的复制人觉醒
```

### 矛盾叠加技巧
**单一矛盾撑不起长篇，需要多层叠加。**

**示例**:
```markdown
## 《三体》的矛盾叠加
- 资源矛盾：三体星系资源枯竭
- 文明矛盾：三体人 vs 地球人
- 技术矛盾：智子锁死基础科学
- 阶级矛盾：面壁者 vs 普通人
- 存在矛盾：黑暗森林法则下的宇宙观
```

## 4. 世界观的"规则感"

### 规则让世界可信
**规则 = 限制，限制 = 故事。**

**规则设计要点**:
```markdown
## 科幻世界观的规则清单

**物理规则**:
- 光速限制（决定星际旅行方式）
- 能量守恒（决定科技天花板）
- 熵增定律（决定宇宙命运）

**社会规则**:
- 星际法律（禁止什么？惩罚什么？）
- 贸易规则（货币？以物易物？）
- 外交准则（如何接触外星文明？）

**技术规则**:
- 科技树（哪些技术先突破？）
- 技术禁忌（为什么某些技术被禁止？）
- 技术副作用（科技的代价是什么？）
```

**示例**:
```markdown
## 《沙丘》的规则体系

**物理规则**:
- 沙丘星球极度缺水（塑造文化）
- 沙虫与香料的共生关系（生态规则）

**社会规则**:
- 大家族制度（政治博弈）
- 宇航公会垄断星际旅行（交通规则）
- 贝尼·杰瑟里特姐妹会（宗教规则）

**技术规则**:
- 护盾技术（快武器失效，回归冷兵器）
- 摄入香料可预知未来（但有代价）
- 人工智能被禁止（巴特勒圣战的历史）
```

## 5. 世界观构建的实操流程

### 第一步：确定核心设定
```markdown
问自己三个问题：
1. 这个世界最大的"不同"是什么？（核心卖点）
2. 这个"不同"如何影响人类社会？（涟漪效应）
3. 这个世界最大的矛盾是什么？（故事引擎）
```

### 第二步：画出世界观地图
```markdown
不需要精确的地图，但需要：
- 关键地点（故事发生地）
- 势力分布（谁控制哪里）
- 资源分布（争夺什么）
- 交通路线（如何移动）
```

### 第三步：写出世界观大纲
```markdown
## 世界观大纲模板
1. **时间背景**: 故事发生在什么时代？
2. **空间背景**: 故事发生在什么地点？
3. **科技水平**: 这个世界有什么科技？
4. **社会结构**: 谁统治？谁被统治？
5. **核心矛盾**: 这个世界最大的问题是什么？
6. **文化特色**: 这个世界的人信仰什么？禁忌什么？
```

### 第四步：填充细节
```markdown
细节是世界观的灵魂：
- 食物（吃什么？怎么吃？）
- 语言（有没有新词汇？行话？）
- 服饰（穿什么？为什么？）
- 节日（庆祝什么？纪念什么？）
- 禁忌（不能做什么？为什么？）
```

## 6. 世界观构建自检清单

- [ ] **时间线清晰**: 从现在到故事发生，中间发生了什么？
- [ ] **空间格局明确**: 故事发生在哪？势力如何分布？
- [ ] **社会结构完整**: 谁统治？阶级如何划分？
- [ ] **核心矛盾突出**: 这个世界最大的问题是什么？
- [ ] **规则体系自洽**: 物理/社会/技术规则是否一致？
- [ ] **细节丰富**: 有没有让读者"身临其境"的细节？
- [ ] **信息展示合理**: 是否通过故事自然展示，而非强行灌输？
- [ ] **与现实有连接**: 读者能否从中看到现实的影子？
