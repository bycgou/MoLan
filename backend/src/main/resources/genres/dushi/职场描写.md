# 职场描写指南 (Workplace Writing Guide)

> **核心原则**: 都市小说中的职场不是背景板，而是角色成长的主战场。好的职场描写 = 真实的权力博弈 + 可感知的专业细节 + 角色能力的可视化展示。

---

## 1. 职场层级体系设计

### 层级 A: 基层员工（实习生/专员）
**特征**: 执行者，受制于人，信息获取有限。

**典型场景**:
```
会议室里，张伟站在角落，手里攥着打印好的方案。
"这个方案谁做的？"总监扫了一眼，随手扔到桌角。
"是我……"
"回去重做。"
张伟张了张嘴，最终什么也没说，默默捡起方案走了出去。
```

**写作要点**:
- 重点描写"被忽视感"和"无力感"
- 通过细节展现地位差距（站位、发言顺序、被对待的方式）
- 埋下日后逆袭的伏笔

---

### 层级 B: 中层管理（主管/经理）
**特征**: 夹心饼干，上有压力下有不满，信息流通的枢纽。

**典型场景**:
```
李婷盯着电脑屏幕上的邮件，上面写着"本月KPI未达标部门：市场部"。
她深吸一口气，拨通了下属的电话："小王，你来我办公室一趟。"
挂断电话，她又打开另一封邮件——总部要求裁员15%。
"这活儿没法干了……"她揉了揉太阳穴。
```

**写作要点**:
- 展现"上传下达"的两难处境
- 描写中层的焦虑感（业绩压力、人事关系、向上管理）
- 中层是职场政治最密集的层级，适合展开博弈

---

### 层级 C: 高层决策（总监/VP/CEO）
**特征**: 掌握资源分配权，视野开阔，决策影响全局。

**典型场景**:
```
"收购还是合作？"陈总把两份方案摆在桌上。
"收购能拿到核心技术，但现金流会很紧张。"
"合作风险小，但对方随时可能翻脸。"
他站起身，走到落地窗前，俯瞰整个CBD。
"通知财务部，准备收购方案。"
```

**写作要点**:
- 决策场景要体现"信息不对称"和"风险权衡"
- 高层对话要简洁有力，避免过多废话
- 展现"一个人的决定影响千人命运"的重量感

## 2. 办公室政治描写技巧

### 技巧 1: 派系斗争的展现方式

**三步展现法**:
```markdown
## 第1步：表面和谐
茶水间里，市场部的王经理和销售部的刘经理有说有笑。
"老刘，上次那个客户多亏你帮忙。"
"哪里哪里，都是一个公司的。"

## 第2步：暗流涌动
回到办公室，王经理关上门，脸色立刻沉了下来。
"小周，去查一下销售部上个月的客户报备记录。"
"王总，您是怀疑……"
"我什么都没怀疑，让你查你就查。"

## 第3步：正面冲突
季度总结会上，刘经理突然发难：
"市场部的推广方案有问题，导致我们丢失了三个大客户。"
王经理不动声色："哦？那请问刘经理，这三个客户的跟进记录在哪里？"
会议室瞬间安静下来。
```

---

### 技巧 2: 常见政治手段及描写

| 手段 | 描写要点 | 示例对话 |
|------|---------|---------|
| **抢功** | 打断汇报、篡改邮件抄送 | "这个项目我全程参与指导的" |
| **甩锅** | 推诿责任、制造证据 | "这个决定是大家一起做的" |
| **站队** | 公开表态、私下示好 | "张总那边我帮你说了好话" |
| **信息封锁** | 不转发关键邮件、会议不通知 | "我以为你知道了" |
| **捧杀** | 过度夸奖、推入火坑 | "这个项目非你不可" |

---

### 技巧 3: 写好会议场景

**会议描写公式**:
```
会议描写 = 座位安排（暗示权力）+ 发言顺序（暗示派系）+ 表决结果（暗示胜负）
```

**示例**:
```
会议室里，张副总坐在长桌左侧第一个位置——这是二把手的位置。
王总监坐在他对面，两人中间隔着长长的会议桌。
"关于新项目的人选，我推荐小李。"张副总率先开口。
"小李经验不足吧？"王总监端起茶杯，"我倒觉得老赵更合适。"
其余人面面相觑，没有人敢接话。
最终，总裁拍了板："让小李试试，年轻人需要机会。"
张副总嘴角微微上扬。王总监面无表情地放下了茶杯。
```

## 3. 职场成长线设计

### 阶段 1: 新人期（适应与观察）
**关键词**: 迷茫、碰壁、学习

**剧情模板**:
```markdown
主角刚入职 → 犯错被批评 → 发现公司潜规则 → 认识关键人物 → 完成第一个小任务
```

**写作要点**:
- 展现"学校学的东西在职场没用"的落差感
- 通过细节展现职场规则（如：领导说话时不要插嘴、邮件抄送顺序有讲究）
- 安排一个"贵人"角色指点迷津

---

### 阶段 2: 成长期（崭露头角）
**关键词**: 机遇、挑战、站队

**剧情模板**:
```markdown
接到棘手任务 → 团队不配合 → 主角独自扛下 → 意外做出成绩 → 引起高层注意 → 卷入派系斗争
```

**写作要点**:
- 成长要有代价（加班、牺牲个人生活、得罪人）
- 避免"一路开挂"，要有挫折和反复
- 展现能力提升的具体表现（从"被安排"到"主动规划"）

---

### 阶段 3: 突破期（独当一面）
**关键词**: 权力、责任、抉择

**剧情模板**:
```markdown
获得提拔 → 面临更大挑战 → 做出关键决策 → 决策带来后果（成功或失败）→ 成为真正的领导者
```

**写作要点**:
- 突破不是终点，而是新困境的起点
- 展现"权力越大，责任越大"的主题
- 通过决策场景展现角色的成长和格局变化

---

## 4. 行业专业细节植入

### 原则: 专业感来自细节，不来自术语堆砌

**错误示范**:
```
"我们要用KPI考核OKR，通过PDCA循环实现ROI最大化。"
→ 读者：每个字都认识，连起来不知道在说什么。
```

**正确示范**:
```
"这个季度的目标很简单——"王总监在白板上写下三个数字。
"第一，新增用户50万；第二，转化率提升到8%；第三，客单价不低于200。"
"完不成呢？"有人小声问。
"完不成，市场部全体降薪20%。"
会议室里一片死寂。
```

---

### 各行业细节速查

| 行业 | 核心场景 | 关键细节 | 常见冲突 |
|------|---------|---------|---------|
| **互联网** | 产品评审、技术选型、上线发布 | 需求文档、bug等级、灰度发布 | 产品vs技术、工期vs质量 |
| **金融** | 投决会、风控审查、路演 | 合规红线、杠杆比例、尽调报告 | 收益vs风险、客户vs公司 |
| **广告/传媒** | 比稿、提案、客户对接 | 创意brief、媒介排期、ROI预估 | 创意vs客户要求、预算vs效果 |
| **地产** | 拿地、开盘、回款 | 容积率、预售证、资金监管 | 政策调控、资金链、合作方 |
| **医药** | 临床试验、审批、学术推广 | GCP规范、不良反应、适应症 | 合规vs业绩、研发周期vs市场窗口 |

## 5. 职场对话的写法

### 原则: 职场对话要有"潜台词"

**表面意思 vs 真实意思**:
```
领导说："这个方案不错，再优化优化。"
表面意思：方案还行，改改就能用。
真实意思：方案不行，但我不好直说，你看着办。

领导说："你最近挺忙的吧？"
表面意思：关心你的工作状态。
真实意思：你手上的项目进度怎么样了？别耽误事。

同事说："你跟张总关系挺好的吧？"
表面意思：羡慕你和领导的关系。
真实意思：你是不是张总的人？我得搞清楚你站哪边。
```

---

### 对话节奏控制

**快节奏对话（紧张场景）**:
```
"方案被驳回了。"
"谁驳的？"
"张总。"
"理由呢？"
"没说。"
"那就去问！"
```

**慢节奏对话（试探场景）**:
```
"小王啊，最近工作怎么样？"
"还行，谢谢陈总关心。"
"听说你跟市场部的人走得挺近？"
"……就是工作上的接触。"
"哦，工作上的接触。"陈总重复了一遍，端起茶杯喝了一口。
"年轻人，多交朋友是好事。但有些朋友，交了就不好脱身了。"
```

## 6. 职场场景自检清单

- [ ] **层级感明确**: 不同层级的人物说话方式、行为举止是否有区别？
- [ ] **专业细节到位**: 行业术语使用是否自然、不堆砌？
- [ ] **权力关系清晰**: 谁是上级、谁是下属、谁是平级，读者能否一眼看出？
- [ ] **潜台词丰富**: 对话是否有言外之意，而不是大白话？
- [ ] **成长有代价**: 主角的职场晋升是否付出了相应代价？
- [ ] **冲突有层次**: 是否有表面冲突和深层冲突的叠加？
- [ ] **场景有细节**: 办公室布置、会议流程、邮件往来是否有真实感？

## 职场描写速查表

| 描写类型 | 核心要素 | 常见错误 | 改进方向 |
|---------|---------|---------|---------|
| **会议场景** | 座位、发言、表决 | 写成流水账 | 聚焦冲突和转折 |
| **领导对话** | 潜台词、权力感 | 领导说话像普通人 | 简洁、有分量、有暗示 |
| **同事关系** | 合作与竞争并存 | 非黑即白 | 展现灰色地带 |
| **晋升过程** | 机遇+能力+关系 | 纯靠能力上位 | 体现复杂性 |
| **离职/裁员** | 情感与利益交织 | 过于煽情 | 保持克制和真实 |
