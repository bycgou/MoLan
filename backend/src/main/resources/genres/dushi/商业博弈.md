# 商业博弈指南 (Business Competition Writing)

> **核心原则**: 都市小说中的商业博弈是权力与智慧的较量。好的商业描写 = 真实的商业逻辑 + 紧张的谈判节奏 + 鲜明的利益冲突 + 角色的格局展现。

---

## 1. 商业博弈的核心要素

### 要素 1: 信息差
**核心**: 谁掌握更多信息，谁就占据主动。

**信息差的类型**:
```markdown
## 时间信息差
- A知道某消息，B还不知道
- 示例：提前获知政策变动、市场风向

## 渠道信息差
- A有特殊信息来源，B没有
- 示例：内部人脉、行业圈子、政府关系

## 专业信息差
- A比B更懂某个领域
- 示例：技术壁垒、行业经验、法律知识
```

**剧情应用**:
```
林天从内部渠道得知：某块地即将被划为商业用地。
他以住宅用地的价格买下，三个月后地价翻了十倍。
"你怎么知道的？"对手质问。
"我比你更了解这个行业。"林天淡淡一笑。
```

---

### 要素 2: 资源博弈
**核心**: 商业竞争的本质是资源争夺。

**关键资源类型**:
| 资源类型 | 描写要点 | 剧情作用 |
|---------|---------|---------|
| **资金** | 现金流、融资能力、资金链 | 制造"没钱了"的危机感 |
| **人脉** | 政商关系、行业圈子 | 展现"关系网"的力量 |
| **人才** | 核心团队、技术骨干 | "挖人"是常见商业手段 |
| **技术** | 专利、核心算法、商业秘密 | 制造"技术被窃"的冲突 |
| **渠道** | 供应商、经销商、客户资源 | 控制渠道=控制命脉 |

---

### 要素 3: 时间压力
**核心**: 商业决策往往有截止时间，时间压力制造紧迫感。

**常见时间压力场景**:
```markdown
## 场景1：融资 deadline
"我们还有7天时间，如果拿不到这笔融资，公司就要破产。"

## 场景2：竞标截止
"标书必须在明天下午5点前提交，晚一秒都不行。"

## 场景3：合同谈判
"对方只给我们24小时考虑，过了这个村就没这个店了。"

## 场景4：危机公关
"舆情发酵的速度比我们想象的快，必须在今晚12点前给出回应。"
```

## 2. 商业谈判描写

### 谈判场景的要素
```
谈判场景 = 座位安排 + 开场试探 + 价码博弈 + 僵局打破 + 最终成交
```

### 谈判阶段详解

**阶段 1: 开场试探**
```
"王总，久仰大名。"林天伸出手。
"林总年轻有为啊。"王总握住他的手，力度不轻不重。
两人坐下，茶水端上来。
"听说贵公司最近在谈一笔大生意？"王总吹了吹茶杯里的热气。
"王总消息灵通。"林天笑了笑，"不过还在初步接触阶段。"
→ 双方都在试探对方的底牌
```

**阶段 2: 价码博弈**
```
"我们出价5000万。"王总报出数字。
"5000万？"林天摇摇头，"王总，这个价格没有诚意。"
"那林总觉得多少合适？"
"8000万。"
"8000万？"王总笑了，"林总，你这是狮子大开口啊。"
"王总，我给你算一笔账——"林天拿出平板，"按照目前的市场行情……"
→ 用数据说话，不是漫天要价
```

**阶段 3: 僵局与破局**
```
"6500万，一分都不能再多了。"王总站起来，作势要走。
"王总留步。"林天不慌不忙，"6500万可以，但我有一个条件。"
"什么条件？"
"我要你们的华南区独家代理权。"
王总停下脚步，重新坐了下来。
"……这个我们可以谈谈。"
→ 僵局时换个筹码，打开新局面
```

---

### 谈判技巧描写清单

| 技巧 | 描写方式 | 示例对话 |
|------|---------|---------|
| **红白脸** | 两人配合，一硬一软 | "我同事脾气不好，我来跟他商量" |
| **最后通牒** | 制造紧迫感 | "这是我们的底线，不行就算了" |
| **欲擒故纵** | 假装不感兴趣 | "其实我们也在跟其他公司谈" |
| **以退为进** | 主动让步换取更大利益 | "价格可以让，但付款方式要改" |
| **声东击西** | 真正目标藏在次要条件里 | 表面谈价格，实际要渠道 |
| **蚕食策略** | 逐个争取小利益 | "再加个售后条款吧" |

## 3. 商战常见模式

### 模式 1: 恶意收购
**剧情结构**:
```markdown
## 第1步：暗中布局
反派通过多个马甲公司，悄悄收购主角公司的股票。

## 第2步：公开逼宫
持股达到一定比例后，公开提出收购要约。

## 第3步：主角反击
- 方案A：寻找白衣骑士（引入友好的大资本）
- 方案B：毒丸计划（稀释对方股权）
- 方案C：金蝉脱壳（转移核心资产）

## 第4步：最终对决
股东大会上的投票大战。
```

**描写要点**:
- 展现资本运作的冷酷和精密
- 通过"持股比例""投票权"等数据制造紧张感
- 主角的反击要有商业逻辑支撑，不能靠"运气"

---

### 模式 2: 商业间谍
**剧情结构**:
```markdown
## 第1步：发现异常
主角发现竞争对手总是能提前一步做出反应。

## 第2步：排查内鬼
缩小范围，锁定嫌疑人。

## 第3步：设局抓鬼
故意泄露假信息，看谁会传出去。

## 第4步：真相大白
内鬼往往是意想不到的人（亲信、老员工、甚至合伙人）。
```

**描写要点**:
- 悬疑感是关键，让读者跟着主角一起猜
- 内鬼的动机要合理（利益、嫉妒、被威胁）
- 抓鬼过程要有策略性，不能靠"偶然发现"

---

### 模式 3: 价格战
**剧情结构**:
```markdown
## 第1步：挑起战争
竞争对手突然大幅降价，意图抢占市场。

## 第2步：被动应战
主角被迫跟进降价，利润大幅缩水。

## 第3步：寻找破局
- 方案A：差异化竞争（我不跟你比价格，我比品质/服务）
- 方案B：联合其他受害者，形成联盟
- 方案C：釜底抽薪（挖走对方的核心供应商）

## 第4步：最终胜负
价格战没有赢家，但活下来的就是胜利者。
```

---

### 模式 4: 技术壁垒
**剧情结构**:
```markdown
## 第1步：技术突破
主角公司研发出核心技术，形成竞争优势。

## 第2步：围追堵截
竞争对手试图挖人、窃密、专利诉讼。

## 第3步：攻防转换
主角用专利武器反击，或找到技术漏洞突破封锁。

## 第4步：行业格局
技术领先者成为行业龙头，制定游戏规则。
```

## 4. 商业场景细节

### 场景 1: 董事会会议
```markdown
## 会议描写要素
- 会议室布置（长桌、投影仪、落地窗）
- 座位安排（董事长居中，左右是核心高管）
- 表决方式（举手、投票、一票否决权）
- 暗流涌动（谁支持谁、谁在观望）
```

**示例**:
```
会议室内，十二位董事分坐长桌两侧。
董事长陈建国坐在主位，面前放着一份收购方案。
"关于收购鼎盛科技的提案，现在开始表决。"
"赞成。"执行董事张明率先举手。
"赞成。"三位董事跟着举手。
"反对。"财务总监摇头，"现金流撑不住。"
"弃权。"两位董事对视一眼，没有表态。
陈建国看了看局势：4票赞成，1票反对，2票弃权。
还有五票没有表态，其中包括他自己。
"我投赞成票。"他举起手，"5票赞成，通过。"
反对派的脸色沉了下来。
```

---

### 场景 2: 投资路演
```markdown
## 路演描写要素
- 台上的表现（PPT、演讲、回答质疑）
- 台下的反应（投资人表情、窃窃私语）
- 关键问答（刁钻问题、精彩回答）
```

**示例**:
```
"请问林总，你们的技术壁垒是什么？"台下一位投资人举手。
"我们拥有12项核心专利。"林天点开PPT。
"专利可以绕过。"投资人不依不饶，"我问的是真正的壁垒。"
林天笑了笑："真正的壁垒是我们的团队。"
他翻到下一页，展示核心成员的履历。
"我们的CTO是前谷歌首席架构师，算法负责人是MIT博士……"
台下的气氛明显热络起来。
```

---

### 场景 3: 资金链危机
```markdown
## 危机描写要素
- 财务数据（现金流、负债率、到期债务）
- 时间压力（几天内必须找到钱）
- 多方反应（银行抽贷、供应商催款、员工恐慌）
- 主角的应对（找钱、砍成本、卖资产）
```

**示例**:
```
"林总，银行那边……"财务总监欲言又止。
"说。"
"他们要提前收回贷款。"
"多少？"
"三个亿。"
林天沉默了。公司账上只剩八千万。
"供应商那边呢？"
"已经在催款了。如果下周不付款，他们就停止供货。"
林天站起来，走到窗前。
外面是繁华的CBD，但他知道，这座大楼里的公司随时可能倒下。
"通知所有高管，今晚8点开会。"
他转过身，眼神变得锐利。
"另外，帮我约一下鼎盛的王总。"
```

## 5. 商业人物塑造

### 商业精英的说话方式
**特征**: 简洁、有逻辑、不废话。

**对比示例**:
```
普通人："我觉得这个方案不太好，因为成本太高了，而且风险也很大，我们是不是可以考虑其他方案？"

商业精英："方案有两个问题：成本超预算30%，风险敞口过大。重新做。"
```

---

### 商业大佬的决策风格

| 风格 | 特征 | 代表人物 | 适用角色 |
|------|------|---------|---------|
| **激进型** | 敢赌敢拼，高风险高回报 | 孙正义 | 创业型主角 |
| **稳健型** | 步步为营，稳扎稳打 | 巴菲特 | 老牌企业家 |
| **阴谋型** | 暗中布局，出其不意 | 影视剧反派 | 商业反派 |
| **理想型** | 情怀驱动，不计代价 | 马斯克 | 理想主义主角 |

## 6. 商业博弈自检清单

- [ ] **逻辑自洽**: 商业操作是否有合理的商业逻辑？
- [ ] **数据真实**: 财务数据、市场数据是否在合理范围内？
- [ ] **节奏紧凑**: 谈判、竞标等场景是否有紧张感？
- [ ] **人物立体**: 商业人物是否有鲜明的性格和决策风格？
- [ ] **冲突清晰**: 商业冲突的核心矛盾是否明确？
- [ ] **细节到位**: 会议室、路演、谈判等场景是否有真实感？
- [ ] **结局合理**: 商战结果是否有铺垫，不是突然逆转？
