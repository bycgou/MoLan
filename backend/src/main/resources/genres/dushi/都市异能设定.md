# 都市异能设定指南 (Urban Supernatural Power Settings)

> **核心原则**: 都市异能的关键是"都市为底，异能为刃"。好的异能设定 = 与现代社会规则的碰撞 + 清晰的能力边界 + 合理的成长路径。

---

## 1. 异能来源设定

### 来源 A: 先天觉醒型
**特征**: 出生时或特定年龄触发，与血脉/基因相关。

**设定模板**:
```markdown
## 觉醒条件
- 触发年龄：通常在16-25岁之间
- 触发方式：极端情绪波动/濒死体验/特定天象
- 觉醒概率：万分之一（稀缺但不至于绝迹）

## 血脉设定
- 普通觉醒者：单系异能，能力一般
- 血脉觉醒者：双系或多系异能，潜力更高
- 远古血脉：极其稀有，能力逆天但有副作用
```

**优点**: 天然制造"天赋差距"冲突，适合成长型主角。

---

### 来源 B: 外部触发型
**特征**: 因意外事件获得能力（实验事故、陨石辐射、古物接触）。

**设定模板**:
```markdown
## 触发事件
- 类型：科学实验泄漏 / 外星物质接触 / 古代遗物激活
- 副作用：能力不稳定、有时间限制、损害身体

## 能力特点
- 与触发源相关（辐射→放射系，古物→符文系）
- 可能需要持续"充能"或"消耗"
- 可能被同类触发源复制或消除
```

**优点**: 能力来源有迹可循，便于制造"能力被夺"的危机。

---

### 来源 C: 规则变异型
**特征**: 世界规则本身发生变化，部分人类适应变异获得能力。

**设定模板**:
```markdown
## 世界观背景
- 某年某月，全球灵气复苏/维度裂缝打开/异界能量入侵
- 人类中约1%发生变异，获得超凡能力
- 变异方向与个人体质/精神状态相关

## 社会影响
- 政府成立专门机构管理异能者
- 普通人对异能者态度复杂（恐惧/崇拜/排斥）
- 异能者内部形成不同阵营
```

**优点**: 世界观宏大，便于展开多方势力博弈。

---

## 2. 异能体系分类设计

### 体系 1: 元素系
**核心**: 操控自然元素（火、水、风、雷、土、冰等）。

**能力分级**:
```
初级：小范围操控（点烟、引水、微风）
中级：大范围操控（火球、水墙、雷击）
高级：元素具现化（火凤凰、水巨人、雷龙）
巅峰：领域展开（方圆百米内元素绝对掌控）
```

**设计要点**:
- 元素之间要有克制关系（水克火、火克冰、冰克风……）
- 元素操控要消耗精神力/体力，不能无限使用
- 高级能力要有副作用（过度使用导致元素反噬）

---

### 体系 2: 身体强化系
**核心**: 强化肉体能力（力量、速度、防御、感知、再生）。

**能力分级**:
```
初级：超越常人2-3倍（一拳打碎砖块）
中级：超越常人10倍（徒手拆墙、子弹时间）
高级：超越常人100倍（刀枪不入、音速移动）
巅峰：肉身成圣（核弹级防御、瞬移级速度）
```

**设计要点**:
- 强化要有侧重，不能全能（力量型速度慢，速度型防御弱）
- 设置能量消耗机制（不能一直保持强化状态）
- 身体强化者需要面对"力量失控"的风险

---

### 体系 3: 精神系
**核心**: 操控精神/意识（读心、控制、幻术、预知）。

**能力分级**:
```
初级：情绪感知、简单读心（表层想法）
中级：记忆读取、精神暗示、初级幻术
高级：精神控制、深层读心、大型幻境
巅峰：意识抹杀、精神领域、群体控制
```

**设计要点**:
- 精神系能力要有明确的"抗性"机制（意志力越强越难被控制）
- 避免精神系过于IMBA，设置冷却时间和范围限制
- 精神系使用者通常身体脆弱，近战能力差

---

### 体系 4: 空间/时间系
**核心**: 操控空间或时间（传送、储物空间、时间暂停、时间回溯）。

**能力分级**:
```
初级：短距离传送、小型储物空间、局部时间减速
中级：城市间传送、中型空间、时间暂停3秒
高级：跨城市传送、大型空间、时间回溯1分钟
巅峰：任意传送、无限空间、时间长河掌控
```

**设计要点**:
- 空间/时间系是最容易写崩的类型，必须严格限制
- 设置重大代价（使用一次消耗寿命/精神力见底/需要冷却数天）
- 避免"时间回溯"成为万能解法

---

### 体系 5: 特殊系（规则类）
**核心**: 操控某种抽象规则（因果、概率、死亡、命运）。

**能力示例**:
```markdown
## 因果律能力
- 能力：将"因"和"果"逆转
- 限制：每天只能使用一次，且必须付出等价代价
- 示例：将"被子弹击中"的因果逆转为"子弹飞回射击者"

## 概率操控
- 能力：小范围改变事件发生的概率
- 限制：只能影响"可能发生"的事件，不能创造不可能
- 示例：让硬币连续100次正面朝上
```

**设计要点**:
- 规则类能力必须有严格的使用条件和代价
- 避免"规则类能力无解"，设计克制手段
- 这类能力适合作为BOSS级角色的杀手锏

## 3. 异能等级体系

### 推荐等级划分（6级制）
```
E级（萌芽）: 能力刚刚觉醒，无法完全控制
D级（掌控）: 可以主动使用能力，但范围和威力有限
C级（精通）: 能力运用自如，可应对常规战斗
B级（大师）: 能力产生质变，可影响大范围区域
A级（王者）: 能力登峰造极，一人可敌一支军队
S级（传说）: 全球仅数人，能力接近"神"的领域
```

### 各等级对应的社会地位
| 等级 | 战力类比 | 社会地位 | 数量（全球） |
|------|---------|---------|-------------|
| **E级** | 普通人+ | 被观察对象 | 数十万 |
| **D级** | 特种兵级 | 异能机构基层 | 数万 |
| **C级** | 小型军队 | 异能机构骨干 | 数千 |
| **B级** | 中型军队 | 组织核心战力 | 数百 |
| **A级** | 大型军队 | 国家级战略资源 | 不超过50 |
| **S级** | 核武级 | 改变世界格局 | 不超过5 |

## 4. 异能与现代社会的碰撞

### 碰撞点 1: 法律与秩序
**核心问题**: 异能者犯罪怎么处理？

**设定参考**:
```markdown
## 异能者管理条例（示例）
1. 异能者必须在管理局登记注册
2. 未经许可，禁止在公共场合使用异能
3. 异能伤人按故意伤害罪加重处罚
4. 异能杀人可判处无期徒刑或特殊监禁
5. 未登记异能者视为"黑户"，一旦发现强制收容
```

**剧情应用**:
- 主角在紧急情况下使用异能救人，却被管理局约谈
- 反派利用法律漏洞，在"灰色地带"使用异能作恶
- 异能者与普通人的法律地位之争

---

### 碰撞点 2: 社会舆论
**核心问题**: 普通人如何看待异能者？

**舆论分化**:
```
支持派："异能者是人类进化的方向！"
恐惧派："异能者太危险了，必须控制！"
嫉妒派："凭什么他们有超能力？不公平！"
崇拜派："异能者是英雄！是神！"
实用派："能不能用异能帮我搬砖？"
```

**剧情应用**:
- 主角救人后被拍视频上网，引发舆论风暴
- 异能者身份暴露后，面临社会歧视或过度追捧
- 普通人组建"反异能者"组织

---

### 碰撞点 3: 经济与就业
**核心问题**: 异能者如何在社会中谋生？

**职业方向**:
| 异能类型 | 适合职业 | 收入水平 | 风险等级 |
|---------|---------|---------|---------|
| **元素系** | 消防员、能源工程师 | 中等 | 高 |
| **身体强化系** | 特警、保镖、运动员 | 中高 | 高 |
| **精神系** | 心理咨询师、谈判专家 | 高 | 中 |
| **空间系** | 物流、快递（笑） | 极高 | 低 |
| **治疗系** | 医生、急救员 | 极高 | 中 |

## 5. 异能战斗描写要点

### 要点 1: 能力可视化
**错误示范**:
```
"他释放了一道火焰攻击。"
→ 读者：什么颜色？多大？多热？什么形状？
```

**正确示范**:
```
他右手前伸，掌心猛然爆发出一团赤红色的火焰！
火焰在空中扭曲、压缩，最终化作一条三米长的火蛇，带着灼人的热浪扑向敌人！
火蛇所过之处，空气被灼烧得扭曲变形，地面留下焦黑的痕迹。
```

---

### 要点 2: 能力克制与博弈
**战斗博弈公式**:
```
战斗结果 = 能力等级 × 属性克制 × 战斗智慧 × 环境利用
```

**示例**:
```
林天（C级水系）vs 赵烈（B级火系）

表面上看：赵烈等级碾压，必胜。

实际上：
- 水克火，属性克制（林天+50%）
- 战斗地点在湖边，环境有利（林天+30%）
- 林天诱敌深入，引赵烈进入水中（战斗智慧）

结果：林天以弱胜强！
```

---

### 要点 3: 能力使用的代价
**代价类型**:
```markdown
## 体力消耗型
- 使用能力会消耗体力/精神力
- 过度使用会昏迷甚至死亡
- 适合：大多数异能体系

## 身体损伤型
- 使用能力会对身体造成反噬
- 等级越高，反噬越轻
- 适合：狂暴型、爆发型能力

## 寿命消耗型
- 每次使用消耗一定寿命
- 大招可能直接减寿数年
- 适合：时间系、因果系等IMBA能力

## 情绪依赖型
- 能力强度与情绪状态挂钩
- 愤怒时能力暴走，冷静时能力削弱
- 适合：精神系、血脉觉醒型
```

## 6. 异能设定自检清单

- [ ] **来源清晰**: 异能从何而来？是否有一套自洽的解释？
- [ ] **体系完整**: 异能分类是否覆盖全面？有无遗漏？
- [ ] **等级分明**: 不同等级之间的差距是否足够大？
- [ ] **代价合理**: 使用异能的代价是否足够重，避免能力泛滥？
- [ ] **克制存在**: 是否有克制手段，避免某种能力无解？
- [ ] **社会融合**: 异能设定是否与现代社会规则产生有趣碰撞？
- [ ] **战斗精彩**: 战斗描写是否可视化、有策略性？
- [ ] **前后一致**: 能力设定是否有前后矛盾？
