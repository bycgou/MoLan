# MoLan 设计文档

本目录是 MoLan 的**实现态设计文档**。每篇描述的都是仓库当前代码里真实存在的东西，
所有论断都给出 `路径:行号` 证据，可逐条回查。

## 编写原则

1. **只写已实现的**。规划中的能力（Provider 自动切换、生成过程暂停续写、流式从检查点续写、
   独立的生成轨迹时间线页、按用户维度的配额限流）一律不写成既有功能；确实属于规划项的，
   在对应分篇里明确标注"当前未实现"。
2. **以代码为准**。文档与代码不一致时以代码为准；发现不一致时改文档表述，而不是让实现去迁就文档。
3. **边界如实记录**。每篇末尾都有"边界 / 已知约束"一节，把降级路径、死代码、未接线的分支讲清楚，
   不做粉饰。**这比罗列能力更有参考价值**——它标出了这套系统实际能承重的地方。
4. **不写敏感信息**。仓库为公开仓库，文档中不出现密码、密钥、真实主机名、内网地址与个人信息。

## 推荐阅读顺序

- **第一次看** → 01 → 03 → 02。01 建立全局印象，03 给出一次生成的完整路径，02 解释背后的引擎机制。
- **改质量规则** → 07 → 06 → 04。
- **调检索 / 调记忆** → 04 → 05 → 08。
- **接前端** → 09 → 01（第 5 节运行形态）。
